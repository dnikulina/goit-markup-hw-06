## Overview

The final version of the WebStudio coursework project is a responsive landing page adapted for mobile, tablet, and desktop screen sizes.

It combines the markup, styling, layout, modal, form, and interaction techniques practiced throughout the previous assignments.

## Tech Stack

- HTML5
- CSS3
- Flexbox
- Responsive Design
- Media Queries
- SVG Icons
- Google Fonts
- Git & GitHub

## Implemented Features

- responsive layouts for multiple screen sizes;
- mobile navigation menu;
- adaptive header and content sections;
- responsive typography and spacing;
- reusable container system;
- hero section with background imagery;
- team and portfolio cards;
- modal window and form;
- interactive hover and focus states;
- responsive images and icon-based interface elements.

## Learning Outcomes

- mobile-first responsive development;
- media queries;
- adapting layouts across breakpoints;
- responsive navigation;
- flexible content grids;
- combining reusable CSS patterns into a complete landing page.
